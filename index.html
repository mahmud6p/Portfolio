Password strength

Estimate how long a password would survive an offline guessing attack. The estimate runs here and nothing is stored.

LOCAL ONLY
Type something to see the estimate.

Assumes randomly generated characters and 10 billion guesses per second. Passwords built from real words, dates or keyboard patterns fall much faster.

Reading the result

  • Bits measure how many guesses an attacker needs, not how “complex” a password looks.
  • Length matters more than swapping letters for symbols.
  • A password manager makes long, unique passwords practical.
  • This is an estimate. It cannot know whether a password has appeared in a breach.

What a hash does to one letter

SHA-256 turns any text into a fixed 64-character fingerprint. Edit one character and watch the highlighted digits change.

SHA-256

The first line is the previous fingerprint, the second is the new one, and the highlighted digits are the ones that changed. A good hash changes about half its digits for any edit.
